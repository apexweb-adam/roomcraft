# Roomcraft design and scope

Original 3D reference study created September 8, 2026, before the Victoria VR hackathon build period. This is a registration reference, not a final hackathon entry and not an AI scene generator.

Selected design: `concept.png`, generated for this task. Full single-screen workspace, warm white #f6f5f0, canvas #eeede6, forest #234a3c, subtle #deded7 borders. System sans typography, heading 48px desktop/32px mobile, controls 14–16px. Header 72px, title and sentence, 72/28 canvas-inspector split with 18px corners, quiet footer. Mobile stacks canvas before controls. Outline cube, reset and fullscreen icons are actual SVG UI. All room assets are original procedural Three.js geometry; the concept is not used as a screenshot background.

Functional additions to concept: accessible object selector (supports keyboard users who cannot raycast), saved-state confirmation, export feedback, WebGL failure message and import of the app's own JSON. The public demo requires no API key, no account, no paid services and no network after bundled assets load. No measurements are engineering or safety certification. Geometric material details are a realtime approximation of the concept; no raster rendering is claimed to be interactive 3D.

Required checks: orbit and zoom; select by canvas and dropdown; object movement/rotation; layout, light, wall and atmosphere updates; reset; JSON export/import; persisted reload; mobile overflow; browser console; built and live asset paths. Final screenshots and fidelity notes belong here, distinct from the generated concept.
